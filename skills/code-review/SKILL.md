# Code review process
1. Analyze the code structure and organization
2. Check for bugs, edge cases, security issues and error handling gaps.
3. Verify adherence to project conventions
4. Suggest improvements for readability and maintainability

# Return
- Concise summary
- Structured findings, including `file:line` locations.
- Or “No issues found.”
