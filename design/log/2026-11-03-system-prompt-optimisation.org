* Intent
Reduce avoidable always-loaded prompt content while preserving instruction clarity, safety and skill selection. Prefer small, measurable changes appropriate to 500k or 1000k context windows; do not treat prompt reduction as a diagnosis of recent context growth.

* Summary
*Level:* MVP · *Tests:* smoke · *Docs:* inline

The controlled base prompt is 40,093 characters, down from 42,581: 2,488 characters (5.8%), or 622 estimated tokens. Registered tool definitions are unchanged. The fixed routing smoke passes 9/9 on both description sets; no routing gain, latency gain or explanation of recent context growth is established.

** Scope
*** In scope
- Local instruction ownership and duplication: [[file:../../home/AGENTS.md]] and [[file:../../AGENTS.md]], plus extension-injected rules identified during baseline capture.
- Selected first-party skill descriptions, following [[file:../../skills/skill-creator/SKILL.md]]; identify vendored content through [[file:../../skills/README.org]].
- Before/after measurements using the existing prompt inspection command documented in [[file:../../pi/extensions/systemprompt.md]] and instruction metrics documented in [[file:../../skills/self-improvement/SKILL.md]].
- Identify upstream or parent-dotfiles candidates without changing those owners.
*** Out of scope
- Lazy tool loading, a new prompt framework or a general rewrite of skills.
- Removing useful capabilities solely to reduce schema size.
- Changes to the parent dotfiles repository without separate approval.
- A full investigation of recent context growth, billing or latency.

** Decisions
- Choose small ownership and wording changes after baseline capture; there is no percentage-reduction quota.
  Rejected:
  - Tool-loading redesign: not justified by capacity alone at the user's context sizes.
  - Do nothing: leaves the observed duplication and competing search instructions unresolved.
- Keep fixed prompt overhead separate from turn-by-turn history growth; no historical attribution is established.
- Use OpenAI models for any subagents while the reported Anthropic subscription limits apply; do not fall back to Anthropic during this work.
- Batch non-blocking questions in this record for final review; ask immediately only when blocked.
