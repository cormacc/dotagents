** Decisions
- Use a compact core plus conditionally loaded references :: reuse existing references and contract sections first; add a focused reference only where reuse would force an unrelated large read. Keep each rule and its necessary caveats together. Rejected:
  - Shortening the current monolith alone: rare branches would still load for ordinary work.
  - Making the core a bare index: loading the safety boundaries would depend on selecting the right reference before the hazard is visible.
  - Moving all extracted text into one mandatory reference: this relocates rather than reduces the ordinary loading cost.
- Preserve instruction meaning, not incident narration :: retain imperatives, negation, exceptions and authority constraints. Existing design history or RETROLOG.org owns examples and benchmark evidence; do not reproduce those examples in another runtime reference.
