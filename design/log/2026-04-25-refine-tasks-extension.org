* Summary
UX and persistence refinements to the pi tasks extension: load-time =:ID:= backfill for TASKS.org and linked plans, merger of compact selected-task surface and expanded =/tasks= UI under a single load/refresh flow, default collapse rules, plan-link display in the details pane, prompt-strategy redesign so create/archive dialogs stay visible, and =STARTED= propagation from plan subtasks to their TASKS.org ancestor. Compact selected-task UI moved from a top-pinned overlay to a reserved above-editor widget so it no longer masks scrollback.

** Decisions
- Default collapse :: collapse completed subtrees by default; always keep the selected path visible; with no selection show only top-level tasks; with a selection expand the selected path and collapse siblings.
- Compact UI placement :: above-editor widget (reserved layout space), not an overlay. Capped at 6 lines.
- Prompt strategy :: temporarily close the expanded tasks UI and use normal =ctx.ui.input= / =ctx.ui.confirm= dialogs, then refresh and reopen.
- ID backfill preservation :: preserve org semantics and unchanged non-task content; do not promise byte-for-byte preservation of rewritten task subtrees.
- =STARTED= propagation :: when any plan subtask first transitions to =STARTED= via the tasks UI, the top-level =TASKS.org= ancestor auto-advances from =TODO= to =STARTED=. Skills updated for the rule and the manual-edit exception.

** Shipped
- Parser helpers for =:ID:= detection and =planError= metadata; load-time UUID backfill for =TASKS.org= and loaded linked plans.
- Compact above-editor widget replaces the top-pinned selected-task overlay; hidden while expanded UI open; refreshed from the shared task graph after.
- Create / archive / plan prompts moved out of the expanded overlay lifecycle so built-in dialogs remain visible.
- Default collapse rules in =TasksOverlay=; linked-plan metadata and load-error display in the details pane.
- =STARTED= propagation in =cycleStatus= (=overlay.ts=): plan subtask → =STARTED= auto-advances the =TASKS.org= ancestor.
- Tasks README and generated =keybindings.org= updated; =org-memory= / =plan= skills updated for propagation rule.
- Compact widget polish: removed bottom divider, full-width top divider, =PLAN: ./relative/path= labels left-aligned with selected-task indent (later dropped the =PLAN: = prefix so the path renders directly).

** Gotchas
- Compact widget height does not always collapse on task deselection: pi TUI framework limitation — =setWidget(id, undefined/[])= does not trigger layout reflow without a terminal resize. Extension code is correct; experimental patches were reverted. Filed for upstream reporting.
