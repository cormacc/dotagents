* Intent

Close the bounded herdr-orch correctness, recovery, and documentation gaps before the Herdr plugin wrapper work starts. The work serialises publication against the lifecycle verbs, moves artefact identity to a publisher-owned work root, adds a parent-owned recovery verb, stops the trait gate from replaying stale Codex credentials, and lands the probe-safety rules and README pass that depend on them.

* Summary

*Level:* production · *Tests:* thorough · *Docs:* README

** Scope

*** In scope

- Serialise `publish`, `close`, `continue`, and the post-settle phase of `poke` with a per-child OS file lock.
- Make `WORK-ROOT` publisher-owned identity and require relative `ARTIFACTS` entries.
- Recover settled children that did not publish, without raw keys or respawn.
- Run trait gates against the caller's real `CODEX_HOME`.
- Add concurrency and scratch-probe guardrails to `home/AGENTS.md`.
- Refresh the herdr-orch README and mechanical contracts.

*** Out of scope

- New orchestration features, the Herdr plugin wrapper, and unmanaged harnesses.
- Cross-skill Babashka and `ot` installation design.
- Synthetic trait re-probes, tracked by task `d669edf5`.

** Acceptance

*** Core functionality

- [X] `publish`, `close`, and `continue` mutate a child's round only while holding that child's exclusive lock.
- [X] `poke` holds the same lock across its final guards, prompt, and `:pokes` update.
- [X] `close` cannot record `:closed-at` while an unconsumed item exists.
- [X] `continue` cannot supersede a round while publication commits an item.
- [X] Result envelopes carry publisher-owned `WORK-ROOT` identity and relative `ARTIFACTS` entries.
- [X] Publication rejects absolute artefact entries and lexical escapes from `WORK-ROOT`.
- [X] A settled, dispatched, unpublished child receives the standard publication prompt.
- [X] Other ledger, dispatch, and settlement states refuse with named reasons.
- [X] Trait-gate token refreshes write to the caller's real `CODEX_HOME`.
- [X] `home/AGENTS.md` contains the tested scratch, timeout, and lock-probe guardrails.
- [X] The README states the final user-facing behaviour without duplicating mechanical contracts.

*** Edge cases

- [X] Lock contention tests assert one-winner/one-loser invariants without assuming acquisition order.
- [X] An `unconfirmed` dispatch reports without prompting.
- [X] Publication rejects blank, absolute, traversal, mismatched-root, and unusable artefact entries.
- [X] Capture rejects a symlinked artefact that resolves outside `WORK-ROOT`.
- [X] The poke lock-boundary test fails against the unlocked implementation and passes against the fix.

*** Anti-criteria

- [X] Must not: add compatibility for the old absolute-artefact envelope.
- [X] Must not: add a caller-controlled barrier to a production lock path.
- [X] Must not: change runtime behaviour in the README pass.
- [X] Must not: restate generic temporary-file rules in the guardrail additions.

** Decisions

- Key the exclusive `FileChannel.lock` by child, not round :: publication against an old round must contend with successor creation. Closing the channel releases the lock, including after process death.
  Rejected:
  - createFile-based locks: require stale-owner recovery.
  - ledger-only transitions: `ledger/update!` is itself an unserialised read-modify-write.
- Keep the settle waits outside the child lock :: each verb re-reads mutable state after waiting. `poke` then holds the lock through its final check, prompt, and count update.
- Make artefact identity publisher-owned :: the ledger supplies `WORK-ROOT`; publication checks lexical containment and capture checks real-path containment.
- Keep recovery parent-owned :: `poke` uses ownership, round, dispatch, and settlement guards. It never sends raw keys or respawns.
- Use the real `CODEX_HOME` for trait gates :: `--ephemeral` and `--ignore-user-config` isolate configuration while token refresh persists.
- Put portable scratch and concurrency rules in `home/AGENTS.md`.

** Shipped

- ADDED per-child exclusion :: `publish`, `close`, `continue`, and post-settle `poke` serialise against publication through `<assignment-root>/.tmp/herdr-orch/ledger/locks/<child>.lock`.
- ADDED publisher-owned `WORK-ROOT` identity :: the ledger, child environment, and result envelope carry one immutable work root across a child lineage.
- MODIFIED the result-envelope `ARTIFACTS` grammar :: entries are relative to `WORK-ROOT`; this is a breaking change without compatibility handling.
- MODIFIED `oh task poke` :: captured `WAITING` and invalid rounds remain recoverable, unconsumed or terminal items refuse, `unconfirmed` dispatch reports, and the final mutation is locked against publication.
- REMOVED `prepare-codex-home!` :: trait gates use the caller's `CODEX_HOME`, so refreshed credentials persist.
- MODIFIED `skills/herdr-orch/scripts/docs/contract.md` :: documents the lock boundaries, `WORK-ROOT`, relative artefacts, capture containment, and final poke ordering.
- MODIFIED `skills/herdr-orch/SKILL.md` :: documents relative artifact declarations and parent-owned publication recovery.
- MODIFIED `home/AGENTS.md` :: adds scratch-target containment, timeout-unit verification, and scheduler-independent lock-test rules.
- MODIFIED `skills/herdr-orch/design.org` and `skills/herdr-orch/README.org` :: record the breaking contract evolution and present the final user-facing behaviour.

** Gotchas

- `FileChannel` lock acquisition is not FIFO on macOS. Tests must accept either winner.
- Real-path containment must resolve both the artefact and work root. Resolving only one rejects valid paths behind symlinked prefixes.
- Contract-string tests must pin the complete expected string. A matching prefix does not constrain appended guidance.

** Risks

- `publish`, `close`, and `poke` can hold the child lock across untimed Herdr or Git calls. A stuck call blocks that child's competing lifecycle operation until the process exits.
- The coordinated `WORK-ROOT` envelope change rejects in-flight pre-change assignments.
- Live ledger entries received inferred `:work-root` values without a before-image. The recorded shared-checkout values matched the observed repository, but the migration cannot be reversed mechanically.
- Concurrent trait gates share one live Codex credential. Refresh ordering remains the Codex CLI's responsibility.

* Implementation

- `with-child-lock` uses the ledger-scoped child name. `publish-round!`, close mutation, continuation reservation, and post-settle poke revalidation use the same exclusion primitive.
- `publish-round!` links immutable items while locked and releases the lock before notification. Continuation takes the child lock before the assignment reservation lock.
- `core/envelope` validates relative artefact shape. Capture resolves both the declared artefact and `WORK-ROOT` with `Path.toRealPath` before it renders links.
- `poke` checks ownership before settling, then re-reads the round under the child lock. The final guard, prompt, and `:pokes` update form one critical section.
- Trait gates pass the resolved caller `CODEX_HOME` directly to `codex exec`; no credential copy or cleanup remains.
- Closeout review added symlink-containment coverage, complete publication-guidance assertions, the corrected `orphans --prune` contract, untimed-lock risks, and the poke publication-race fix.
