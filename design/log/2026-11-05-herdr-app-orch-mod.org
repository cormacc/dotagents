* Intent
Provide a herdr-orch-owned quota status item and popup in herdr-app, using the same quota source as the TUI integration. Adapt the upstream UI and combine it with a separate Linux/macOS system-load companion in a managed personal layout.

* Summary
*Level:* MVP · *Tests:* thorough · *Docs:* README

** Scope
*** In scope
- ~herdr-app/mods/herdr-orch/~ (quota status item and popup), ~herdr-app/mods/system/~ (system load), ~herdr-app/layouts/herdr-orch.json~ and ~herdr-app/README.md~, with upstream MIT notices and provenance.
- Offline tests under ~herdr-app/tests/~, run by ~scripts/test-herdr-app.bb~ from ~bb test~.
- Parent ~/dotfiles/agents.nix~: individual out-of-store links for the mods and the personal layout.
*** Out of scope
- Remote quota collection, new quota providers, credential handling, AMD/Intel GPU collection, Windows, orchestration panels and a UI redesign.
- Changes to ~herdr-plugin/~, ~herdr/config.toml~, shipped app mods/layouts, or unrelated settings changes.

** Shipped
- Quota status item and popup: validated ~oh usage --format json~ data from the home-installed ~oh~, one shared refresh coordinator, 60-second polling and the app's native 30-second command limit.
- System-load companion: Linux and macOS CPU/RAM, NVIDIA-only Linux GPU, and the Activity Monitor action only for local macOS.
- Personal layout ~herdr-orch~, based on the shipped ~main~ layout of herdr-app 0.1.10. The user selects it explicitly.
- Parent ~agents.nix~ links each leaf individually and rejects foreign occupants.
- [[proj:skills/herdr-orch/scripts/docs/contract.md]] section 'Usage' is unchanged: the mod consumes the existing contract.

** Gotchas
- Native popup toggles need the ~check_box~ accessibility role; native checking rejects ~checkbox~.
- When you save a linked mod's source, the app does not reload the mod. ~touch -h~ on the mod link, or an app restart, loads the change. ~herdr-app/README.md~ documents this limit.
- ~herdr-app check~ covers only initial rendering. Asynchronous states need offline tests and native interaction.

** Decisions
- Adapt upstream UI :: Preserve its native rendering, responsive behaviour, keyboard support and relevant preferences; replace collection, schema mapping and stale handling. Upstream-only provider integrations, remote quota logic and the login-shell fallback are not retained. A fresh rendering implementation was rejected.
- Direct JSON invocation :: Use ~exec(home() + "/.agents/skills/herdr-orch/scripts/oh", ["usage", "--format", "json"], {cwd: home()})~. Check the exit code and the ~herdr-orch/v1~ success envelope before consuming ~result.providers~. Normal refresh respects collector cache/backoff; no ~--fresh~ by default. Text/status formats lose popup structure.
- One local quota snapshot :: The status instance owns polling; the popup shares a refresh coordinator and state, not another timer. Shared keys/assets/overlay references are isolated under the mod identity. ~localProvider~ gives row identity and ~provider~ only adapter presentation. Quota is labelled as this computer; the system companion keeps upstream selected-machine behaviour.
- 60-second polling, native 30-second command limit :: The app's ~herdr.d.ts~ declares the 30-second ~exec~ limit, so no background collector or timeout wrapper is needed. The TUI integration keeps its own interval.
- Failure policy :: Retain a failed-command snapshot for at most five minutes, stale immediately, then show unavailable. Transport age stays separate from provider freshness. Provider failures from a valid new snapshot supersede old rows; authentication-invalidated numbers are never restored. UI state uses safe categories, not raw stderr.
- Separate system companion :: Preserve upstream collection and attribution. The Activity Monitor action is disabled unless running locally on macOS. Linux CPU/RAM plus NVIDIA-only GPU support is accepted.
- Managed leaf paths :: Link each mod directory and the personal layout individually through the parent's out-of-store mechanism; never manage the whole app directory. Refuse collisions. Installation does not switch layouts.
- Linked-source reload :: Accepted as a known limit on 2026-11-09 rather than a change of installation strategy.

** Risks
- The copied layout does not receive upstream structural updates. ~herdr-app/README.md~ records its provenance and the manual refresh procedure.
- Schema drift in ~oh usage~ can hide unavailable providers or fabricate window semantics. Fixtures cover aliases, empty windows, unknown durations, model scopes and stale/auth failures; only finite in-range percentages are retained.
