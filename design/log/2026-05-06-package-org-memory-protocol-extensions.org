* Summary
Added an in-repo dual-mode package around the org-memory subset (=org-tasks=, =org-plan=, =org-jira= skills; =tasks=, =jira=, =leader-menu=, =emacsclient= pi extensions; =extensions/lib/= helper modules). Editable mode keeps the existing whole-directory =mkOutOfStoreSymlink= wiring for the dotfiles owner; packaged mode exposes the explicit org-memory resource set via per-entry symlinks from a Nix store derivation, so collaborators get exactly the documented bundle and nothing else. =agents/package.json= manifest lets pi install the bundle directly via =pi install=. User settings (=settings.json=, =tasks-ext.json=, =jira-ext.json=, =leader-menu.json=) are out of scope and remain dotfiles-local.

** Decisions
- =agents/skills= stays generic :: harness-agnostic; targets =~/.agents/skills= for pi, Claude Code, Codex.
- =agents/pi= stays pi-specific :: targets =~/.pi/agent/{skills,extensions}=.
- Package only the org-memory slice first :: avoids accidentally publishing unrelated personal workflow extensions.
- Editable mode for the dotfiles owner :: whole-directory symlinks; the entire local suite is installed.
- Packaged mode for collaborators :: per-entry symlinks from the Nix store; only the explicit resource set.
- Don't package settings :: package exposes resources, not opinionated defaults.
- Pi package metadata without forcing pi-native installation :: Nix/Home Manager remains the primary install path for this repo.
- Defer repository extraction :: prove the package boundary in-place first.
- Manifest single source of truth :: =agents.nix= reads the slice from =agents/package.json= via =lib.importJSON=, so adding/removing an entry in the manifest flows through to packaged-mode symlinks without touching Nix.

** Shipped
- =agents/package.json= manifest declaring =pi.extensions= and =pi.skills= with explicit slice paths; =peerDependencies= of =@mariozechner/pi-coding-agent=, =@mariozechner/pi-tui=, =@sinclair/typebox= at =*= (pi bundles these — never =dependencies=).
- =agents/agent-org-memory.nix= derivation filtering the slice via =lib.fileset.unions= intersected with a file-level predicate dropping =*.test.ts=, =test.sh=, =default.nix=.
- =flake.nix= output =packages.<system>.agent-org-memory= for =x86_64-linux= and =aarch64-darwin=.
- =agents.nix= rewritten with =agents.mode= enum (=editable= default, =packaged=) and =agents.package= option. Editable mode preserves the original six whole-directory symlinks byte-for-byte; packaged mode generates per-entry symlinks plus the =lib= helper (eight entries total).
- =agents/README.md= covers both install modes, why generic vs pi-specific resources land in different roots, extraction roadmap, and what the bundle does *not* ship.

** Gotchas
- Pi resolves =../lib/…= imports from the *symlink path* under =~/.pi/agent/extensions/<ext>/=, not the realpath. Packaged mode therefore must also create =~/.pi/agent/extensions/lib= as a symlink to the helper directory; otherwise all four packaged extensions fail to load with =Cannot find module '../lib/…'=. The lib directory has no =index.ts= / =package.json=, so pi's scanner skips it as an extension candidate while still resolving sibling imports. The spike's "no lib symlink needed" decision was wrong and is corrected here.
- =nix flake check --impure --no-build= reports a pre-existing =home.homeDirectory= conflict in =nixosConfigurations= that reproduces on master before this change — not a regression.
- =emacsclient/test.sh= reports 53/54 (one =tsx= resolution failure under the ad-hoc nix shell wrapper); reproduces on master.

* Implementation

** Manifest spike
Reference: pi 0.73.0 docs (=packages.md=, =extensions.md=, =skills.md=) and extension loader at =dist/core/extensions/loader.js=.

*** Manifest shape

#+begin_src json
{
  "name": "@cormacc/agent-org-memory",
  "version": "0.1.0",
  "description": "Org-memory task protocol skills + pi extensions",
  "keywords": ["pi-package"],
  "pi": {
    "extensions": ["./extensions"],
    "skills": ["./skills"]
  },
  "peerDependencies": {
    "@mariozechner/pi-coding-agent": "*",
    "@mariozechner/pi-tui": "*",
    "@sinclair/typebox": "*"
  }
}
#+end_src

Key rules from pi source:
- =pi.extensions= is an array of paths/globs. For each entry pi loads direct =*.ts=/=*.js= files, subdirectories with =index.ts=/=index.js=, or subdirectories with their own =package.json= carrying a =pi= field. Subdirectories with *none* of these (e.g. =extensions/lib/=) are silently skipped, so helper directories cohabit safely.
- =pi.skills= is an array of paths/globs. Skills are directories containing =SKILL.md=; pi recurses.
- Globs support =!exclude= patterns and consumer-side filtering (=+path= / =-path=) in =settings.json=. Not needed for the first cut.
- Without a =pi= manifest, pi auto-discovers from convention dirs (=extensions/=, =skills/=, =prompts/=, =themes/=) — equivalent to declaring them explicitly. We ship the manifest so the slice is documented in-tree.

*** Dependencies
Import audit of the four packaged extensions plus =lib/= (excluding tests) shows only =@mariozechner/pi-coding-agent=, =@mariozechner/pi-tui=, =@sinclair/typebox=, and =node:*= builtins. Per pi docs the three packages are bundled by pi itself and *must* be declared as =peerDependencies= with =*= — never =dependencies=, never bundled.

*** Install paths for collaborators
Three viable routes:
1. =pi install npm:@cormacc/agent-org-memory= — standard route once published.
2. =pi install git:github.com/cormacc/dotfiles= — clones, runs =npm install=, resolves the =pi= manifest. Works without npm publish.
3. =pi install /path/to/store= — local path entry written to =settings.json= without copying. What Home Manager's packaged mode produces: per-entry symlinks under standard locations reference store paths directly. Pi treats them as ordinary auto-discovered locations.

** Boundary and manifest
Source-tree additions only: =agents/package.json= and =agents/README.md=. Editable mode unaffected because HM symlinks bypass the manifest entirely — pi auto-discovers from the convention dirs.

The manifest's =files= list deliberately excludes =agents/AGENTS.md= (owner-facing pi instructions) and =agents/skills/README.org= (dotfiles-internal index).
