* Summary
Added Jira integration as a new =jira= pi extension and =org-jira= skill, layered on top of generic external-issue support added to the =tasks= extension. =tasks= and the =org-tasks= / =org-plan= skills stay tracker-agnostic: =tasks= renders =:LINKED_ISSUES:= badges and resolves bare keys against =#+ISSUE_URL_BASE=, with =J= opening URLs in the browser. All Jira-specific knowledge (MCP routing, workflow names, =#+JIRA_*= keywords, slash commands) lives in =jira= and =org-jira=. Slash commands =/jira clone=, =/jira claim=, =/jira comment=, =/jira create= are agent-prompt builders — the extension is I/O-free; the agent performs MCP calls via the existing =atlassian= MCP server. =/jira clone= seeds new tasks; =/jira claim= / =/jira comment= operate on the existing =:LINKED_ISSUES:= list; auto-transition reacts to =tasks:status-changed= events.

** Decisions
- New =jira= extension and =org-jira= skill :: keep =tasks= and =org-tasks= / =org-plan= tracker-agnostic; Jira's surface will grow.
- =:LINKED_ISSUES:= drawer property + =#+ISSUE_URL_BASE= keyword :: multi-valued; tokens are bare keys (resolved against the URL template) or full =[[URL][LABEL]]= org links; forms mix freely. Tag form (=:MBFW-123:=) rejected to avoid polluting the =:tag:= namespace.
- =:LINKED_ISSUES:= created on first use, never backfilled :: mirrors =:STARTED:= behaviour. New tasks don't pre-create the drawer entry.
- =jira= writes bare keys, not org links :: org-link form reserved for non-templatable trackers; keeps =/jira clone= / =/jira create= compact.
- Subtasks are independent issues :: don't mirror org parent/child onto Jira Epic/Story/Sub-task. Each task carries its own (possibly empty) =:LINKED_ISSUES:=; relationships expressed in the org tree.
- All Jira access via the =atlassian= MCP server, agent-driven :: extension is I/O-free; slash commands draft prompts.
- Two-tier UX :: read-only badge / browser-open works without =jira= installed; workflows that touch Jira require =jira= and =atlassian= MCP.
- Sandbox-only writes :: all write-path smoke tests against the =SAND= project.
- Graceful degradation when MCP offline :: display + browser navigation work unconditionally; MCP-dependent paths surface a "run /mcp reconnect atlassian" notification.
- Confluence out of scope :: noted as a follow-up.

- =jira= is optional: =tasks= renders badges and opens URLs without it.
