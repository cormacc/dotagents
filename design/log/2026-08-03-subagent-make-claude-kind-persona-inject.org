* Intent

Make `oh start <persona> --kind claude` work again by switching the Claude persona transport from multiline body text in `agent start` argv to the shell-safe `--append-system-prompt-file <path>` flag, keeping kind resolution and the pi path untouched, and closing the fake-harness gap that let the broken transport pass the suite.

* Summary

*Level:* production · *Tests:* thorough · *Docs:* inline

** Scope

*** In scope
- Claude-kind persona injection via `--append-system-prompt-file` + absolute persona path (`core.clj` `persona-system-prompt` -> per-kind flag/value pairs; `cli.clj` `spawn!` native-args assembly).
- `fake-herdr` fidelity: reject control characters in `agent start` agent args with the real `invalid_agent_argument` envelope, before pane checks.
- Unit coverage (`core_test`, `cli_test` `persona-system-prompt-dialect`) for the per-kind argv.
- Guarded live smoke (`bb smoke-subagent`) able to exercise `--kind claude`.
- One contract.md line documenting the per-kind persona transport.

*** Out of scope
- Any change to kind or model resolution, weight aliases, or `config.edn` row-replacement/merge semantics.
- Runtime Claude version probing or a fallback body-text transport.
- Prompt-text changes ("Read <path>, adopt that role" stays for all kinds).
- Persona injection for kinds other than pi/claude.

** Acceptance

- [X] Claude-kind spawn argv carries `--append-system-prompt-file` + the resolved absolute persona path → test:`scripts/test/herdr_orch/cli_test.clj` `persona-system-prompt-dialect`

*** Anti-criteria

- Must not: alter composed prompt text.

** Decisions
- Chose persona path via `--append-system-prompt-file` (claude) :: lossless, symmetric with pi's path transport, no new machinery; verified against installed Claude Code 2.1.220 (flag parses; validates file existence).
  Rejected:
  - Drop system-prompt injection for claude, rely on the "read and adopt" prompt: demotes persona from system level; weakens the harness-agnostic contract.
  - Flatten body to a single line: lossy for markdown structure, ugly, still fragile.
- `persona-system-prompt` returns the complete flag+value pair per kind :: the bug lived in `cli.clj` hardcoding `--append-system-prompt` for both kinds; moving flag choice into core removes the split-brain.
- Fake-herdr models the observed Herdr 0.7.5 contract (reject `\n`, `\t`, `\r` in agent args; quoting-hazard chars and long values pass) :: makes the regression structurally impossible to reintroduce silently for any kind.

** Shipped

- MODIFIED `skills/herdr-orch/scripts/src/herdr_orch/core.clj` :: `persona-system-prompt` becomes `persona-args`, returning the per-kind flag/value pair.
- MODIFIED `skills/herdr-orch/scripts/src/herdr_orch/cli.clj` :: `spawn!` assembles native args from `persona-args`; `home-directory` now prefers `$HOME`.

- MODIFIED `bb.edn` :: `smoke-subagent` doc names `ORCH_LIVE_SMOKE_KIND`.

** Gotchas

- Herdr reports `agent_session` for pi panes only. A claude child's ledger `:child-session` is legitimately `null`, which is why the field is best-effort by contract; only pi may be asserted strictly.
- Babashka's `user.home` ignores `$HOME`, so before this change a real `~/.agents/subagents/config.edn` leaked into every `fake-env` subprocess. The suite was hermetic only while that file did not exist.
- A `task run` timeout is not a failure. Both claude smoke failures reported "child did not publish COMPLETE" while the children went on to publish valid envelopes minutes later.

** Risks
- Older Claude CLI without `--append-system-prompt-file` fails at startup with `unknown option`; introduction version unconfirmed in the public changelog. Accepted: failure is loud and immediate; verified floor 2.1.220 documented inline.
- Real Herdr may reject more than the three probed control characters. Accepted: fake models the observed contract; live smoke covers the real binary.
- `--append-system-prompt-file` semantics vs `--append-system-prompt` (docs state it appends file contents to the default system prompt; interactive-mode parse verified). Residual risk accepted; claude-kind smoke run is the backstop.

* Validation

Reproduction and constraint probes (live Herdr 0.7.5, planning session 2026-08-03):
- `herdr agent start probe --kind claude --pane bogus-pane -- --append-system-prompt "$(printf 'line1\nline2')"` → `{"error":{"code":"invalid_agent_argument","message":"agent arguments cannot be encoded safely for the target shell"},"id":"cli:agent:start"}`; rejection precedes pane lookup (same command with a single-line value fails later with `agent_pane_not_found`).
- Rejected: `\n`, `\t`, `\r`. Accepted: `$VAR`, backticks, single/double quotes, 4000-char values.
- Claude Code 2.1.220: `--append-system-prompt-file /nonexistent-path.md` → `Error: Append system prompt file not found: ...`; unknown flags error with `unknown option`, so the flag demonstrably parses.
