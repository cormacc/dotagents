* Intent
Remove three reproduced sources of misleading org-tasks behaviour without weakening compatibility or test coverage. Make test invocation, launcher root resolution, and completion diagnostics explicit and verifiable.

* Summary
*Level:* production · *Tests:* thorough · *Docs:* full

Explicit test namespaces now validate before loading, both skill script directories delegate tests to the repository root, every `ot` launcher preserves the caller directory, and doctor warns when a `DONE` task retains exact unchecked criteria. The change retains existing discovery, failure propagation, root-resolution policy, and read-only diagnostics.

** Scope
*** In scope
- Validate explicit test namespaces before namespace loading.
- Make `bb test` from each skill's `scripts/` directory delegate to the repository-root suite.
- Remove the root-only warnings that those delegates replace.
- Preserve the caller's working directory in every `ot` launcher shape.
- Add an ordered warn-level doctor finding for `DONE` tasks that contain unchecked criteria.
- Update the living contracts affected by the retained behaviour changes.

*** Out of scope
- Task 19920e17-b7d0-4272-9de2-2a4353271fa9 and its backlog review.
- An archive-scoped `ot show` option or archive-query redesign.
- CI configuration or an `OT_TEST_PARALLELISM` pin.
- Automatic mutation or repair by `ot doctor`.
- A diagnostic for unchecked criteria on `CANCELLED` tasks.
- A diagnostic for open tasks whose criteria are all checked.
- Changes to test selection, parallel execution, fixture handling, or result aggregation.

** Decisions
- Keep only three reproduced failures :: the runner, launcher, and doctor tasks each have a measured failure and a bounded correction.
  Rejected:
  - Retain the CI review task: no tracked CI job or reproduced timing failure exists.
  - Add archive-scoped `show`: the documented scan/unarchive workflow covers the observed need, while a parser-only archive loader would omit canonical imported plan descendants.
- Validate explicit runner arguments against discovered test namespaces :: reject option-like tokens and unknown namespaces before `require`.
  Rejected:
  - Catch and rewrite `require` failures: this can hide genuine namespace load failures.
- Add thin script-directory delegates to the root task :: two delegate files replace four root-only warnings and two misleading failure paths.
  Rejected:
  - Duplicate dependencies or suite definitions under each skill: the copies would drift.
- Mirror the no-`cd` launcher pattern from `skills/herdr-orch/scripts/oh` :: anchor the bare-skill classpath with `--deps-root` and leave root resolution in Clojure.
  Rejected:
  - Resolve `--root` in Bash: this creates a second root policy.
- Diagnose only `DONE` plus exact unchecked syntax :: `CANCELLED` normally leaves unmet criteria, and the inverse open-task case is a weaker signal.
  Rejected:
  - Add a shared checklist abstraction: two consumers do not justify another concept.
  - Auto-check or close tasks: doctor remains read-only.
