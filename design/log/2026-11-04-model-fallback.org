* Intent
Let an interrupted task move to an explicitly permitted model without losing launch provenance or repeating uncertain external effects. Distinguish a new successor session from continuation of the original child.

* Summary
*Level:* MVP · *Tests:* thorough · *Docs:* README

Read-only comparison complete for CCL, Agent Router and Sova at the revisions below. Recommend a parent-authorised successor with an explicit handoff before considering automatic retry. No package, fallback policy, credentials or launch code has changed.

** Scope
*** In scope
- Allowed fallback targets, failure evidence and immutable launch provenance.
- Explicit successor handoff after settlement, with worktree and external-effect reconciliation.
- A harness-specific proof boundary before any automatic resend.
*** Out of scope
- Inferring safe retry from terminal error text alone.
- Rewriting a round's original model alias, canonical model or harness identity.
- Installing an external router, switching accounts or replaying live assignments during research.

** Acceptance
Proposed criteria; not yet approved.
*** Core functionality
- [ ] Allowed fallback aliases and harness kinds are explicit and independently resolved for the successor.
- [ ] Original round identity remains unchanged and links to the new successor.
- [ ] Unknown side-effect state requires parent authorisation and a handoff, not automatic replay.
*** Edge cases
- [ ] Rate limits, quota exhaustion and authentication errors are classified separately.
- [ ] A failed successor launch retains actionable evidence without erasing the original round.
- [ ] Concurrent succession attempts cannot launch duplicate successors.
*** Anti-criteria
- [ ] Must not: treat a plain-text transcript as complete tool-effect history.
- [ ] Must not: change provider or harness silently behind an existing model alias.
- [ ] Must not: infer an idle/done process has a safely replayable last turn.

** Decisions
- Recommend explicit succession first :: the current launch ledger already distinguishes requested alias, canonical model, native arguments and harness kind. A new session must have its own resolved identity. Rejected:
  - Import CCL as automatic recovery: its session adapter deliberately drops tool/internal events, so transcript transfer is insufficient evidence for replay safety.
  - Adopt Agent Router as runtime recovery: the reviewed launcher handles task routing and handoff; the comparison did not establish recovery of an already-running tool-bearing turn.
  - Generalise Sova's login retry: it is transport-specific and refuses resend after output surfaces; that signal is not a generic guarantee about all external effects.
- Keep automatic retry unapproved :: begin with unknown proof state for any harness that lacks a verified pre-dispatch boundary. A provider error string does not establish that no action ran.

** Risks
- A successor can inspect Git state but cannot reconstruct arbitrary external mutations from it.
- Cross-harness transcript conversion can discard tools, attachments or reasoning; handoff must state what is known and uncertain.
- Failure classification and account recovery are provider-specific and can change independently of model alias configuration.
