* Intent
Show the remaining subscription quota of each herdr-orch provider in the Herdr tab-bar status area, so that the operator sees the allowance that `oh` routing reads without running `oh usage`. Use the same quota-axi executable, configuration chain and allowlisted evidence as `oh usage`, and ship the plugin parts inside the planned `cormacc.herdr-orch` wrapper plugin.

* Summary
*Level:* MVP · *Tests:* smoke · *Docs:* README

Herdr plugin v1 cannot add tab-bar or footer items, so the display is a `[ui] tab_bar_right` command entry that runs `oh usage --format status` (for example `anthropic 96%s 36%w | openai-codex 88%w`); `tab_bar_position = "bottom"` turns the tab row into a footer. The `cormacc.herdr-orch` plugin adds a popup pane with `oh usage --format text` as a per-provider list, and an action that prints the config stanza for installs that Home Manager does not manage. On this machine, Home Manager links `~/.config/herdr/config.toml` out of store to `agents/herdr/config.toml`. Routing gives an unscoped candidate the `all_models` scope, so Opus, Sonnet and Haiku receive quota credit without config.

** Scope
*** In scope
- `oh usage --format status`, and `--format text` as a per-provider list.
- `herdr-plugin/` manifest (id `cormacc.herdr-orch`) with a `quota` popup pane and a `quota-stanza` action; the wrapper record (task 9f667467) extends it.
- Tracked Herdr config `agents/herdr/config.toml` and its dotfiles `agents.nix` link.
- Routing default: an unscoped candidate uses `all_models`; Fable selects `model:fable`.
- macOS test runs: the runner skips `^:linux-only` measurement tests and names them.

*** Out of scope
- Doctor and setup panes, link classification and other wrapper scope (task 9f667467).
- Installation of quota-axi. `quota-axi-setup install` stays an explicit operator step.
- Providers that quota-axi does not support (for example Kiro), and credential reads outside quota-axi.
- A local cache, backoff or stale-value retention. Upstream `--max-age 5m` reuse is the only reuse.
- Colour. Herdr removes ESC sequences from command output.
- Windows.

** Decisions
- Display through a `tab_bar_right` command entry :: plugin v1 has no native tab-bar or footer API; `tab_bar_position = "bottom"` is the footer option. Rejected:
  - Plugin-provided footer or tab-bar widget: not in plugin v1.
- Render in `oh` (`--format status` and `text`) :: one place for every `oh usage` renderer, covered by the herdr-orch suite; the plugin stays an adapter. Rejected:
  - Plugin-local Babashka script over `oh usage --format json`: a second renderer outside the herdr-orch tests.
  - Direct quota-axi call, as in the prior art: duplicates discovery, version pinning, bounds and the allowlist.
- Quota parts ship inside the `cormacc.herdr-orch` wrapper plugin :: one plugin per skill; the wrapper scaffold task extends this manifest. Rejected:
  - Separate quota plugin: a second id and README for one pane and one action.
  - No plugin: no detail pane, and no stanza help for installs without Home Manager.
- Unavailable providers show a short marker :: a silent blank hides a broken setup. Herdr clears the entry after a non-zero exit, so `status` exits 0 for every marker. Fresh evidence without a session, weekly or monthly window shows `?`. Rejected:
  - Hide unavailable providers.
- Window labels come from `kind` (`s`, `w`, `m`) :: the evidence has no window duration, so `5h` or `7d` labels would be guesses. `model` windows show only in the pane, to keep the line short.
- `text` is a heading per provider with `- name :: value` lines and UTC reset times :: chosen by the operator for the pane. Rejected:
  - A two-column table: reset times wrap in the popup.
- An unscoped routing candidate uses the `all_models` scope also when other scopes exist :: least configuration; only a model with its own limit (today Fable, `model:fable`) needs a selector. Rejected:
  - Explicit `:quota-scope "all_models"` only: a selector on every Claude model.
  - The lowest known scope: under-credits Opus, Sonnet and Haiku when Fable's own limit is lower.
- Herdr config lives in `agents/herdr/config.toml`, linked with `mkOutOfStoreSymlink` from `agents.nix` :: live-editable, the same pattern as the other agent config. Rejected:
  - Home Manager `programs.herdr.settings`: a store copy, or with `mutableSettings` a merge into an untracked file; neither is live-editable from the repository.
- The tab-bar command runs `~/.agents/skills/herdr-orch/scripts/oh`, with `interval_seconds = 60` and `timeout_seconds = 75` :: Herdr runs it with the active pane's cwd, so the project config layer applies. Upstream `--max-age 5m` limits vendor reads to one in each 5 minutes.
- `^:linux-only` test metadata :: the contract refuses measurement outside Linux; the runner skips and names those tests rather than letting them fail or pass silently. Rejected:
  - A Linux guard inside each test body: a silent pass on macOS.

** Gotchas
- On macOS, Claude Code keeps its live credential in the Keychain, and `~/.claude/.credentials.json` can be stale. quota-axi reports `auth_required` until the operator runs `quota-axi --provider claude --allow-keychain-prompt` once and chooses "Always Allow"; later reads without the flag then succeed.
- Herdr runs tab-bar commands through `/bin/sh -lc` with the server's environment. On nix-darwin, `/etc/profile` rebuilds `PATH` from `$USER`, so `bb` and `node` come from `/etc/profiles/per-user/<user>/bin`.

** Risks
- A Herdr command that rewrites `config.toml` by rename (for example `herdr config reset-keys`) can replace the Home Manager link with a regular file. Accepted: `ls -l` shows it, and the next switch reports the collision.
- Pinned upstream Codex can refresh native credentials although `--no-credential-refresh` is passed. The 60 s tab-bar caller makes this more frequent; the 5-minute upstream reuse limits it.
- A future model-specific quota scope (for example `model:opus`) is routed on `all_models` until `config.edn` names it.
- The tab-bar `command` entry has no documented minimum Herdr version. The manifest floor stays at 0.9.1; evidence is Herdr 0.9.5 only.

* Implementation
- `oh usage` reads the config at each call, so a `config.edn` edit needs no reload. An invalid config makes the status command exit non-zero, and Herdr then clears the entry.
