* Intent
Close the gaps in our learning loop that the EveryInc compound-engineering-plugin (CE, MIT, evaluated at commit =ee3695a=) handles better: retro remembers what the user rejected and checks whether accepted rules worked, fixes take the cheapest durable form, planning finds lessons in earlier change-records, user decisions are not reopened without evidence, deferred review findings are not lost, and a retro can see friction that repeats across sessions. Adapt the ideas to our existing stores (=RETROLOG.org=, =design/log/=, =ot=, =herdr-orch=) rather than import CE's machinery.

* Summary
*Level:* production · *Tests:* smoke · *Docs:* inline

Six changes to =retro=, =self-improvement=, =org-plan=, =org-execute= and the =reviewer= persona. One new Babashka script locates and extracts pi sessions for the wide-scope retro; everything else is skill text.

** Scope
*** In scope
- =RETROLOG.org= as the retro decision ledger: =:KIND: rejected= entries, and =:SIGNAL:= on =:KIND: rule= entries.
- A cheapest-fix order in =self-improvement= routing, used by =retro=.
- Prior-record lookup in =org-plan= drafting, and a durability test for =** Gotchas= at closure.
- Settled-decision provenance labels on =** Decisions= entries, honoured by planners and the =reviewer= persona.
- Durable residuals for unfixed review findings in =org-execute=.
- A wide-scope retro over pi sessions of the repository, its worktrees and Herdr child checkouts: =skills/retro/scripts/sessions.bb=, a reference for the wide procedure, and a session-miner brief.
- A weekly wide-retro offer at session closeout, driven by a run entry that each wide retro writes to =RETROLOG.org=.
- Attribution to CE in =PROVENANCE.md= (=org-plan=, =org-execute=) and =skills/retro/README.md=.
- =evals.json= cases for the changed =retro= and =org-execute= behaviour.
*** Out of scope
- Claude Code and Codex transcripts in the wide retro.
- A separate ledger file, or a retro cutoff stored anywhere other than =RETROLOG.org=.
- A =solutions/= learnings store.
- Review depth by consequence, reviewer lenses, the independence rule, the wave contract and cross-model receipts (evaluated; not selected).
- Restructuring =org-plan= into a phase-loaded kernel.
- Any change to =home/AGENTS.md= or the repository-root =AGENTS.md=.

** Decisions
- Chose =RETROLOG.org= as the retro decision ledger :: it is already searched by rule heading before each change, so rejections and signals sit beside the evidence they qualify.
  Rejected:
  - CE's JSON ledger with a Python helper: a second store and a Python dependency, against the Babashka-first rule.
- Chose pi sessions only for the wide retro (settled: user-directed -- over pi + Claude Code + Codex, and over pi now with the others as a follow-up task).
- Chose a weekly wide-retro offer at session closeout (settled: user-directed -- over an on-demand-only wide retro).
- Chose a =:KIND: wide-run= entry in =RETROLOG.org= as the interval marker :: the default window runs from the last such entry; a declined offer also writes one, so the offer does not repeat at every closeout. A user-named window overrides the default.
  Rejected:
  - CE's per-harness cutoff record: a second store.
  - A marker under =.tmp/=: not shared across worktrees and lost when scratch is cleared.
- Chose session selection by the =cwd= in each session header :: exact, and covers worktrees and Herdr checkouts.
  Rejected:
  - Matching pi's path-encoded directory names: the encoding maps both =-= and =/= to =-=, so it cannot tell =dotfiles/agents= from =dotfiles-agents=.
- Chose read-only =scout= children seeded with a miner brief :: no new persona; mining runs inline when Herdr is absent.
  Rejected:
  - A new =miner= persona: adds to the roster for one workflow.
- Chose =design/log/= =** Gotchas= and =** Decisions= as the project-lesson store :: 91 of 141 records already have a Gotchas section; the gap is lookup, not storage.
  Rejected:
  - A CE-style =solutions/= store: duplicates the records.
- Chose one canonical cheapest-fix order in =self-improvement= :: =retro= cites it. =org-plan= closure keeps its own short order for project lessons (check, then contract document or comment, then Gotcha) and routes agent-process lessons to =self-improvement=.

** Risks
- A settled label used to shield a weak decision from review :: the label never lowers defect severity; a reviewer reports contrary evidence as a conflict on the decision.
- Prompt injection from transcripts :: transcripts are data; miners are read-only and derive no command from them.
- pi changes its session format :: =sessions.bb= checks the header =version= and fails by name.
- Skill-body growth :: token budget anti-criterion; wide-retro detail lives in a reference.
- Merge with the parallel Emacs-tabs branch :: this branch adds one =TASKS.org= entry in =Improvements= and touches no Herdr tab files.
