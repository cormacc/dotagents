* Summary
Added a first-class condensed memory layer so future agents can rebuild context from a small, stable surface before reading the full execution ledger. =* Summary= is now a top-level section required on every change-record (any size, any status past Draft), superseding the legacy =** Outcome= / =** Shipped= heading under =* Implementation=. =* Context= is demoted from required to optional and is promoted only when durable rationale exceeds what =* Summary= can carry. =org-tasks= teaches a layered resume read order that loads =* Summary= first, then =* Context= (when present), =:HANDOFF:=, blockers, open questions, and actionable plan items, deferring full =* Implementation= and completed plan bodies. A closure-time prompt in the tasks extension nudges the agent to generate =* Summary= when a top-level task transitions to =DONE= and the linked change-record either lacks the section or has not been touched since =:STARTED:=. Convention applied retrospectively to 32 records across =agents-src=, =~/dotfiles=, and =~/nmd/products/connect/portal=.

** Decisions
- Layered memory, not less detail :: granular plans and implementation notes preserved for auditability; =* Summary= is the default agent-ingestion surface.
- Section name :: =* Summary= over =* Memory= — matches existing =** Outcome= / =** Shipped= language; "memory" is the purpose, not the name.
- =* Summary= supersedes =** Outcome= / =** Shipped= :: one canonical condensed surface, not two. Retrospective summaries absorb prior outcome text and remove legacy headings.
- =* Summary= always-on; =* Context= optional :: inverts the original threshold model. Size no longer triggers summarize-or-not; it triggers splitting/archiving instead.
- Closure discipline lives in skill *and* tasks extension :: skill is the durable contract; extension prompts on =DONE= when =* Summary= is missing or stale (file mtime predates =:STARTED:= with 60s grace).
- Comprehensive retrospective backfill :: all existing change-records across the three known org-memory repositories adopt =* Summary= in this same change. The earlier "existing records are not bulk-rewritten" carve-out was a v1 artefact, retired.

** Shipped
- =skills/org-plan/SKILL.md= :: =* Summary= required on every change-record; =* Context= demoted to optional with promote-when-rationale-exceeds-synopsis rule; closure-time refresh workflow; retrospective-sweep guidance; minimal skeleton drops =* Context=.
- =skills/org-tasks/SKILL.md= :: layered resume read order; =Agent memory= names =* Summary= as the cheap reconstruction surface; size reframed as a *splitting* criterion.
- =skills/org-jira/SKILL.md= + =skills/README.org= :: cross-reference the new section structure.
- =pi/extensions/tasks/scaffold.ts= :: emits =* Summary=, =* Plan=, =* Implementation= only.
- =pi/extensions/tasks/summary.ts= + =summary.test.ts= :: pure helpers (=hasSummaryHeading=, =parseOrgTimestamp=, =evaluateSummaryRefresh=) detecting missing/stale =* Summary= for the closure-time prompt; 15 tests.
- =pi/extensions/tasks/index.ts= + =overlay.ts= :: new =summaryOnDone= setting (default true); =summaryRefresh= workflow request; =buildSummaryRefreshPrompt= agent prompt; proactive scaffold and closure-time summary refresh are mutually exclusive (no =#+IMPORT:= triggers scaffold path; with =#+IMPORT:= triggers summary refresh).
- =parser.test.ts= snapshot regenerated; =memory.test.ts= covers the resume read order; =README.md= documents the convention and the =summaryOnDone= setting.
- Retrospective sweep across 33 records (23 =agents-src= + 2 =~/dotfiles= + 8 =~/nmd/products/connect/portal=) — see plan tasks =7377277f= (initial 9-record length-gated sweep) and =b376bf99= (comprehensive sweep covering remaining 24). =rg '^\* Summary$' design/log/= shows full coverage in all three repos. Single untracked =2026-05-08-bootstrap-a-clojure-development-skill.org= intentionally out of scope.

** Gotchas
- =* Summary= should link to follow-up TASKS.org tasks rather than burying new work in prose.
- Retrospective sweeps preserve =:CUSTOM_ID:=, =#+PARENT:= links, LOGBOOK history, plan task status, and existing =* Implementation= audit detail. Summary absorption is condensation, not rewriting.
- Closure-time prompt is best-effort: sandboxes the change-record path under =cwd=, silently skips when the file can't be read, falls back to no-prompt rather than failing the close.
- 60s mtime grace window in =evaluateSummaryRefresh= prevents same-minute saves from looking stale; longer grace would require richer LOGBOOK comparison.

** Follow-ups
- Selected-task memory digest command was deferred (plan task =32f00426=). Open a TASKS.org follow-up only if a concrete need emerges (multi-record digests, harnesses that can't read change-records cheaply).
- =~/dotfiles= records still use legacy =:ID:= / =#+PARENT_ID:= rather than =:CUSTOM_ID:= / =#+PARENT:= link form. Migration tracked separately.
- Short historical records without =* Summary= can adopt the new section opportunistically when next touched.
