* Intent
Replace locally maintained subscription collection with one pinned quota-axi CLI boundary. Reduce maintained code while adding subscription information for Kimi and Z.AI, without transferring routing policy to the dependency.

* Summary
*Level:* production · *Tests:* thorough · *Docs:* README

One pinned CLI owns subscription collection; local code owns evidence validation and routing policy. Shared user-local setup requires explicit invocation or Pi confirmation. Pi 1.5 is the supported minimum. Production/config is 202 lines smaller, including setup and Pi integration.

** Scope
Subscription evidence collection, config validation, routing input, CLI/Pi reporting, offline fixtures and the four declared living contracts. Multiple accounts, verified Pi/native identity, new routing candidates, in-session failover, another backend/cache, implicit installation during collection/routing and live provider checks remain out of scope. Explicit shared setup, confirmed Pi setup and the owner-approved Pi 1.5 SDK/minimum/adapter alignment are in scope.

** Shipped
- ADDED :: bounded =quota-axi@0.1.69= CLI boundary, owned process-group guardian and explicit/confirmed user-local setup; Kimi/Z.AI usage-only mappings.
- MODIFIED :: provider config uses =:quota-provider= and optional candidate =:quota-scope=; routing uses fresh validated effective subscription scopes; CLI/Pi reports use allowlisted schema-5/6 provider arrays. All four =#+SPEC:= documents describe setup and the replacement contract. The development SDK and native catalogue/effort adapter contracts target Pi 1.5.
- REMOVED :: local credential extraction, vendor HTTP/normalisation, cache/backoff/locks and the old public window schema. Model IDs, ranks and harness restrictions are unchanged.

** Gotchas
- The operator must approve setup or install the pinned CLI explicitly, and keep Pi/native logins on the same subscription. Identity agreement is an assumption, not a check. Missing evidence remains eligible as unknown under the existing rank policy.
- Native Codex app-server refresh remains possible despite =--no-credential-refresh= and is accepted. The separate Claude delegate stays disabled; the operator may need periodic native Claude authentication. No upstream Pi-support PR is a delivery prerequisite.
- No local negative cache or stale-credit guarantee remains. Provider reads can take longer or repeat more often; the wrapper bounds execution and returns fixed unknown reasons.

** Decisions
- Pi runtime :: Pi 1.5 is the owner-approved minimum, superseding older-Pi support. The development SDK and adapter contracts match it; managed Anthropic effort uses a fixed low top-level baseline and per-message effort markers.
- One supported CLI :: =quota-axi@0.1.69= with Node >=22.19; one explicit shared user-local setup script, also called by Pi after confirmation. No implicit routing-time installer, deep imports, fork or second backend. Upstream collectors are not public root exports, so selective reuse would retain both mechanisms. Version validation is bounded to 5 seconds.
- Confirmed setup :: prefer a managed user-local executable, with PATH fallback for existing installs. Do not edit shell startup files or require elevated permissions. Validate Node and the exact executable version; install with lifecycle scripts disabled. Pi prompts only in an interactive user flow; explicit upgrades also require confirmation. Setup never authenticates providers or reads quotas. The initial manual-only prerequisite is superseded by this owner-approved amendment.
- Upstream collection ownership :: argv =--json --full --no-credential-refresh --max-age 5m --provider <ids>=; =--fresh= selects age zero. Request only needed providers. Clear snapshot/profile-expansion/swap overrides without removing legitimate OAuth/native-home selectors.
- Single subscription per provider :: accept one upstream row, including coalesced keys; multiple rows are ambiguous/unknown, never maximum headroom. No account-key or per-harness identity configuration.
- Exact subscription evidence :: use =quotaSemantics.effectiveAvailability= without recomputing minima or scores. Validate finite 0..100 percentages and resolved subscription =boundedBy= references; reject credits/USD, stale/windowless/unresolved/conflicting evidence. A sole =all_models= scope can default; model scopes require exact reviewed config. Unknown scopes cannot inherit account credit. The shipped Opus selector =seven_day_opus= was checked against the pinned source.
- Local routing policy :: retain rank/reserve/config order, harness filters, explicit-string bypass, inheritance and refusal before allocation. Legacy =:usage=, =:credentials= and =:cache-ttl-s= rows fail with a migration diagnostic. Whole-row override semantics are unchanged.
- Public/process boundary :: retain the =herdr-orch/v1= envelope but replace its result with an allowlisted providers array preserving upstream schema 5 or 6. Strip identity, locators, arbitrary errors and descriptions. Collection is bounded to 60 seconds, cleanup to 2 seconds and stdout to 1 MiB; discard stderr. Pi usage calls allow 75 seconds. Cleanup targets the owned POSIX process group, not unrelated sessions.
