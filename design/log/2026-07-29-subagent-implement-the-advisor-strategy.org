* Intent

Make Anthropic's advisor strategy (cheap executor consulting a frontier advisor at judgment moments) available as an opt-in, comparable alternative to the existing frontier `worker` — implemented harness-side via two new personas and skill guidance, with zero changes to the subagent contract, envelope, or spawn-gating semantics.

* Summary

*Level:* MVP · *Tests:* smoke · *Docs:* inline

** Scope

*** In scope

- New global-roster persona =subagents/advisor.md=: frontier consult-only advisor (opus-5, leaf, =retro: false=).
- New global-roster persona =subagents/advised-worker.md=: cheap executor (sonnet-5) with `spawns: scout researcher advisor` and a defined consultation policy.
- =cli.clj= `delegation-guidance` wording generalised so a spawns list containing `advisor` reads correctly; pinned prompt test in =core_test.clj= updated.
- =skills/herdr-subagents/SKILL.md=: opt-in advisor-strategy section, including advisor tier selection via `--model` override.

*** Out of scope

- Changes to `worker`, `planner`, `reviewer`, `scout`, `researcher` personas.
- Persistent/resident advisor machinery, CLI re-tasking, multiple results per pane.
- Anthropic API `advisor_20260301` usage; Herdr core changes.

- A separate `sage.md` fable-5 persona — tier is a `--model` routing parameter.

*** Anti-criteria

- Must not: modify =worker.md=, =planner.md=, =reviewer.md=, =scout.md=, =researcher.md=
- Must not: change the result envelope, ledger schema, or spawn-gating semantics
- Must not: add resident/re-tasking CLI machinery

** Decisions

- Ephemeral, subagent-owned advisor consults :: each consultation is a fresh blocking below-root spawn granted via the advised-worker's `spawns:` list. Harness-side there is no shared context to preserve (a focused-context handoff must be composed either way), evidence supports ~1 consult/task, and the existing depth/publish/pane contract handles it with zero CLI mechanics changes.
  Rejected:
  - Persistent orchestrator-owned advisor provided by reference: requires re-tasking residents (publish is exactly-once per task; no `ask` command) and child-to-orchestrator's-advisor communication violates the no-child-to-child rule.
  - Subagent-owned resident advisor: no re-tasking mechanism; persistence buys nothing without shared context.
- Review-weighted consultation policy :: mandatory pre-publish review consult (advisor reads trajectory summary + working diff, returns pass/fail checks) plus optional escalation consults (debug dead-end after 2+ failures; high-stakes ambiguous decision), soft cap 3. Fireworks ablation: review-only ≥ plan+review in 5/6 cells at half the consults; a mandatory planning consult does not pay for itself.
- Advisor tier via `--model` override, not a separate persona :: model resolution precedence (flag > frontmatter) already works below root, and spawn gating restricts persona names, never models; labels embed the model basename so runs stay distinguishable. A `sage.md` would duplicate an identical body to change one line.
- Tier escalation is caller-driven :: an advisor never spawns an advisor. The depth bound makes it mechanically impossible below root, and the advisor must stay "pure brain, no hands". The advised-worker re-consults once at fable-5 tier on a defined trigger instead.
- New `advised-worker` persona rather than changing `worker` :: exploratory/opt-in; keeps a stable frontier baseline for the paired comparison.

- ADDED =subagents/advised-worker.md= — sonnet-5 executor, `spawns: scout researcher advisor`; mandatory token-budgeted pre-publish consult, two escalation triggers, soft cap 3, caller-driven one-time fable-5 tier re-consult.

- MODIFIED =skills/herdr-subagents/scripts/src/herdr_subagents/cli.clj= — `delegation-guidance` trigger generalised to "a factual gap or material judgment blocks progress" (applies to every spawning persona's composed prompt).
- MODIFIED =core_test.clj= (pins rewritten deliberately, advisor-bearing list added) and =cli_test.clj= (`fake-env` isolated fixture rosters + `advisor-strategy-spawn-contract` integration coverage).

** Risks

- A sonnet-5 executor may skip the mandatory consult or dump transcripts; mitigated by a numbered workflow step and a concrete consult-context template with token budgets. The paired comparison (task:1a2fdaa6) is the compliance check.
- Per-consult cost exceeds the API version's 400–700 tokens (fresh opus spawn re-orients from scratch); accepted for exploratory work, bounded by blocking one-at-a-time consults and the cap of 3.
