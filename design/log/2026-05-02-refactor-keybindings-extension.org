* Summary
Replaced the ~3000-line =keybindings= monolith with two focused extensions: =leader-menu= (~700 LOC) for leader-chord discovery and dispatch, and =vim-mode= (~2100 LOC) for the modal editor. Decision-then-execute: =kepatrick/vim-motions-pi= evaluated up front against the full =VimEditor= feature set and =KEEP_OWN= chosen (the package lacks dot-repeat, indent operators, bracket text objects, BIG-WORD motions, and visual case toggle — ~30% of daily usage). The two extensions communicate purely through events and load independently. =/kb= and =keybindings.org= are gone; =/leader-menu bindings --export= replaces the hand-maintained reference.

** Decisions
- Two extensions, not three :: =leader-menu= owns menus + cross-extension API; =vim-mode= owns the modal editor; shared helpers in =extensions/lib/=.
- Decision before split :: =vim-motions-pi= evaluated up front → KEEP_OWN.
- Breaking changes, one-step migration :: slash commands, settings file, event names renamed freely; in-tree consumers updated atomically.
- =/kb= dropped entirely; no alias shim.
- =keybindings.org= replaced by an auto-export to eliminate drift.
- Final state: vim-mode always on when loaded :: post-split commit =3939073= removed the runtime toggle; =modal= / =/vim-mode= command / =vim-mode.json= are gone. Disabling means not loading the extension. Only =debug= migrated; now owned by =leader-menu.json=.

** Shipped
- =pi/extensions/leader-menu/= and =pi/extensions/vim-mode/=; original =keybindings/= directory removed.
- Cross-extension API: =registerLeaderMenu()= (consumed by =tasks=, =term=, =git-diff=); events =leader-menu:register=, =leader-menu:ready=, =leader-menu:keys-resolved=, =leader-menu:open=.
- =/leader-menu bindings --export= prints the live-merged binding tree in the same format as the retired =extensions/keybindings.org=.
- Settings: =~/.pi/agent/leader-menu.json= owns =globalLeader=, =localLeader=, =debug=. =vim-mode.json= no longer exists.
- Bare leader keys in Normal mode open leader-menu's standard centered overlay (replaces the legacy 500 ms in-editor widget hint) via the =leader-menu:open= event.
- =,= (repeat-find-backward) added to the vim grammar — the one upstream-inspired gap closed.

** Gotchas
- Default local leader =,= conflicts with Vim repeat-find-backward; in Normal mode comma is handled by Vim grammar first. Use =alt+,= or configure =localLeader= to a non-conflicting key (e.g. =;=) for bare Normal-mode local menu access.
- Final settings shape (after follow-up commits =3939073=, =df7b890=) supersedes the initial split contract — the latter is preserved under =* Implementation= as audit history only.

* Implementation

Below preserves the historical split contract and the evaluation that drove the KEEP_OWN decision. Sections marked *audit history* were superseded by later commits — see =* Summary → Decisions= for the final state.

** Cross-extension delegation — =leader-menu:open= (task =0634cd5f=)

vim-mode delegates bare Space/=,= chords in Normal mode without sharing leader-tree state:

#+begin_src typescript
  // leader-menu/index.ts
  pi.events.on("leader-menu:open", async (data: { rootKey?: string }) => {
    if (!currentCtx) return;
    await showLeaderOverlay(currentCtx, data?.rootKey ?? " ");
  });

  // vim-mode/index.ts (handleNormalMode)
  if (key === " " || key === ",") {
    this.emitLeaderOpen?.(key);
    return;
  }
#+end_src

Replaces the legacy 500 ms widget hint with leader-menu's standard centered overlay (matching =alt+space= in Insert mode). No shared state, no shared imports.

** Split contract (task =5e5260d0=, *audit history*)

Final state superseded by:
- =3939073= removed =/vim-mode=, =vim-mode:enable=/=:disable=, =vim-mode.json=, the =modal= toggle.
- =df7b890= replaced raw trigger-key menus with =globalMenu= / =localMenu= slots and user-resolved leaders in =leader-menu.json=.
- Source of truth for =globalLeader=, =localLeader=, =debug= is now =leader-menu.json=.

Original ownership table (mapping every public surface to its new home — preserved for traceability):

| Surface                                | Old (keybindings)                  | New                              |
|----------------------------------------+------------------------------------+----------------------------------|
| Slash — modal toggle                   | =/kb mode emacs= / =/kb mode vim=  | =/vim-mode on=/=off= (later removed) |
| Slash — bindings list                  | =/kb bindings=                     | =/leader-menu bindings=          |
| Slash — bindings export                | (none)                             | =/leader-menu bindings --export= |
| Event — ext-registered menu (in)       | =keybindings:suggest=              | =leader-menu:register=           |
| Event — ready signal (out)             | =keybindings:ready=                | =leader-menu:ready=              |
| Event — enable/disable modal (in)      | =keybindings:set-mode-vim/-emacs=  | =vim-mode:enable=/=:disable= (later removed) |
| Settings file                          | =keybindings-ext.json=             | =vim-mode.json= (later =leader-menu.json=) |
| Default leader config                  | =keybindings/defaults.json=        | =leader-menu/defaults.json=      |
| Global shortcuts =alt+space=, =alt+,=  | keybindings                        | =leader-menu=                    |
| =VimEditor= class + grammar            | keybindings                        | =vim-mode=                       |
| Helper                                 | =suggestKeybindings()=             | =registerLeaderMenu()=           |
| Helper type                            | =KeybindingSuggestion=             | =LeaderMenuRegistration=         |

Helper rename rationale: =suggestKeybindings= was a misnomer — the helper only ever handled leader-menu entries. The renamed verb matches pi's existing =registerCommand= / =registerTool= / =registerShortcut= pattern. Argument shape and return value kept byte-identical so call sites needed only an import + identifier swap.

** Evaluation: =kepatrick/vim-motions-pi= vs current =VimEditor=

Date: 2026-05-02. Source at https://github.com/kepatrick/vim-motions-pi @ v0.1.3 (~2400 LOC across =vim-motion.ts=, =buffer.ts=, =core.ts=, =clipboard.ts=).

*** Coverage table

| Capability                         | vim-motions-pi      | Our =VimEditor=      |
|------------------------------------+---------------------+----------------------|
| Modes (normal/visual/visual-line)  | yes                 | yes                  |
| Char motions =h j k l=             | yes                 | yes                  |
| Word motions =w b e=               | yes                 | yes                  |
| BIG-WORD =W B E=                   | *no*                | yes                  |
| Buffer motions =gg G=              | yes                 | partial (=G= yes; =gg= via cmd dispatch) |
| Find =f F t T= + =;=               | yes                 | yes                  |
| Repeat find backward =,=           | yes                 | *no* (added here)    |
| Operators =d c y=                  | yes                 | yes                  |
| Indent/dedent =< >=                | *no*                | yes                  |
| Toggle case =~=                    | *no*                | yes                  |
| Visual case toggle =u U=           | *no*                | yes                  |
| Text objects =iw aw iW aW ip ap=   | yes                 | yes                  |
| Quoted text objects =i" a" i' a'=  | partial (="= only)  | yes (=" ' `=)        |
| Bracket text objects =i( a( …=     | *no*                | yes                  |
| Counts =3w 5x 2dd=                 | yes                 | yes                  |
| Dot-repeat =.=                     | *no* (README)       | yes                  |
| Clipboard sync                     | yes (off/yank/all)  | *no*                 |
| =alt+escape= abort handling        | *no* (uses Esc)     | yes (CSI-u shim)     |

*** Decision: KEEP_OWN

Gaps blocking ADOPT, in order of daily impact: dot-repeat, indent/dedent operators, bracket text objects, BIG-WORD motions, visual case toggle, =alt+escape= abort handling. Together ~30% of daily Vim usage in pi. EXTEND would mean maintaining a fork of a moving target plus our deltas — strictly more work than shipping our own =VimEditor= as =vim-mode=.

Things stolen from upstream: decomposition shape (follow-up =6b087caf=), repeat-find-backward =,= (added in this work), clipboard sync (follow-up =08678bfb=). =alt+escape= shim stays — resolves the deferred design question.
