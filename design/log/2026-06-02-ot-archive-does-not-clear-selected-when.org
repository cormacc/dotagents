#+STATUS: Complete

* Intent
~ot archive~ must clear ~#+SELECTED:~ in TASKS.local.org when the archived task
(or any descendant) is the current selection, so archiving never leaves a
dangling selection that ~ot doctor~ flags as ~selected-not-found~.

* Summary
*Level:* MVP · *Tests:* smoke · *Docs:* inline

~archive-cmd~ (skills/org-tasks/scripts/src/org_tasks/commands.clj) is the single
writer for both the headless CLI and the pi overlay (the overlay routes through
~ot archive~). It moved the task and rewrote the parent link but never touched
~#+SELECTED:~, so archiving the selected task (or its parent) left the keyword
pointing at the archived id until ~ot select --clear~ was run by hand.

Fixed by clearing the selection in ~archive-cmd~ after a successful non-dry-run
archive whenever ~selected-id~ is anywhere in the archived subtree.

** Scope
*** In scope
- Clear ~#+SELECTED:~ in ~archive-cmd~ when the archived subtree contains the
  current selection.
- Surface the clear in the command result payload (~:selectionCleared~).
- Clojure regression coverage.
*** Out of scope
- Overlay TypeScript changes — it already calls ~ot archive~ and inherits the fix.
- Any change to ~ot select~, ~ot publish~, ~ot unpublish~, or doctor logic.

** Decisions
- Fix in ~archive-cmd~ (the single org-tasks writer) :: both CLI and overlay
  paths converge there, so one change fixes both surfaces.
  Rejected:
  - Clear selection in the pi overlay archive handler: would diverge the
    headless CLI path and duplicate logic README already attributes to archive.
- Match the archived top-level id *and* descendants :: selecting a subtask then
  archiving its parent must also clear; mirrors ~doctor~'s notion that the
  selection points anywhere inside the archived tree.

** Shipped
- ~archive-cmd~ clears ~#+SELECTED:~ on successful non-dry-run archive when the
  selection is in the archived subtree, and returns ~:selectionCleared~.

** Gotchas
- The selection clear must run only on a real write — it lives inside the
  existing ~(when-not (:dry-run opts) ...)~ block so ~--dry-run~ never mutates
  the selection.
