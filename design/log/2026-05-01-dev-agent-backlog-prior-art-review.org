* Summary
Review-and-implement change-record for the [[https://github.com/farra/dev-agent-backlog][dev-agent-backlog]] prior-art review. Decided adopt/defer/reject across nine candidate ideas, ratified org-native =:BLOCKED-BY+:= continuation lines for multi-valued blockers, and shipped both the protocol updates and the supporting tasks-extension code in a single change-record. Durable HTML review summary at [[file:2026-05-01-dev-agent-backlog-review-summary.html]].

** Decisions
- Multi-blocker carrier :: =:BLOCKED-BY+:= org continuation lines. Local =:BLOCKED-BY:= retained; upstream =:WAITS_FOR:= rejected. Native org syntax round-trips cleanly; backward-compatible with single-value usage; avoids comma/URL ambiguity; each blocker independently editable.
- =:HANDOFF:= placement :: allowed on both top-level tasks and plan-subtask headings; surfaced by resume tooling.
- =#+STATUS:= :: advisory only; no state-machine enforcement at the protocol level.
- =** Outcome= body convention :: short closing paragraph under =* Implementation= summarising what landed (later superseded by the top-level =* Summary= layer added in =design/log/2026-05-09-org-memory-condensed-summaries.org=).
- Solution / lesson capture :: deferred; routed to the self-improvement skill review (TASKS.org task =64a816ea=) rather than the task-lifecycle protocol.
- Non-goals enumerated :: no transient checkout/reconcile backlog as core model; no Claude-specific core metadata; no transcript links by default; no bidirectional tracker sync by default; no human-readable IDs replacing UUIDs; no per-task attribution fields while solo + git-log-attributed.

** Shipped
- Skill updates: =org-tasks/SKILL.md= gains multi-blocker, =:HANDOFF:=, non-goals, and an extended resume checklist; =org-plan/SKILL.md= gains =#+STATUS:= lifecycle, =OPEN= / =DECIDED= question conventions, acceptance-criteria + =** Outcome= body conventions, and resume-time surfacing notes.
- Tasks extension parser API: multi-valued drawer property accessors, blocker classification, =isTaskReady= predicate, =:HANDOFF:= accessors. Single-value =:BLOCKED-BY:= round-trips byte-identically; the new continuation-line convention is dogfooded in this change-record.
- Tasks overlay surfaces =Handoff= and =Blocked by= blocks (with task-ref resolution and readiness colour) on the cursor task's right pane.
- =/tasks doctor= with seven health checks (duplicate IDs, broken imports, stale selection, blockers, stale parent status, =CLOSED:= without timestamp, invalid task blockers) and jumpable-location findings; runs clean on the live dotfiles graph.

** Gotchas
- Three previously top-level TASKS.org tasks were migrated into =* Plan= under this change-record (SKILL updates =d49dad0e=, parser + ready-query =3b5918d5=, =/tasks doctor= =77a0ce57=) preserving UUIDs, =:CREATED:=, LOGBOOK, body content.
